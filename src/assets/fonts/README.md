# Screenshot font

`JetBrainsMonoNerdFontMono-Regular.ttf` is the unmodified JetBrains Mono 2.304
regular face patched by Nerd Fonts 3.4.0, copied from the locally installed
JetBrainsMono Nerd Font distribution. Sources:

- https://github.com/JetBrains/JetBrainsMono
- https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0

SHA-256: `f01031f40e48dc29e1112e6b0b0450a2c6cd097f3f35cfff05c55cb311f8034c`.

See `OFL.txt` for the font's SIL Open Font License and `LICENSE-Nerd-Fonts` for
Nerd Fonts' included component licensing. Both travel with the source asset.
The binary embeds this font for portable screenshot rendering with fontdue.
Bold and italic are synthesized. Host fonts, font fallback, color emoji, cursor
shape/blink and terminal-specific antialiasing are not reproduced. Unsupported
glyphs use the font's missing-glyph representation.
