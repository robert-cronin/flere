# Flere 0.3.11

Automatic Codex goal continuations and native agent messages can begin a turn without a user-prompt hook. Flere now recognizes those turns from the exact running conversation's recorded metadata, preventing repeated hook failures and allowing inbox notices to reach the agent again. Changed turn identities require recorded evidence from that conversation; drafts, active work and native approval prompts still defer queued messages.

Worker startup guidance now distinguishes creating a fresh worker, reusing a live chat and resuming a stopped conversation. An already-open blank chat can receive its first authorized assignment through inspected terminal input before a conversation ID exists. Flere no longer directs that case to an impossible UUID resume. Native approval refusals retain their separate recovery requirements.

From 0.3.10, use **Ctrl+Space, Shift+K**, verify the offered version, then **Enter** to apply. Over SSH, the updater handles the remote core and local companion together. This release targets Linux x86_64 GNU and the Windows x86_64 companion; it adds no macOS prebuilt. Linux prebuilts require glibc 2.39 or newer.

The hook regression exercises the real supervisor, socket, hook adapter and owned process transcript with a harmless native stand-in. This does not establish live model acceptance or physical Windows desktop acceptance.

[Release run 35296248945](https://github.com/robert-cronin/flere/actions/runs/35296248945) passed Linux and Windows validation and published from source `361ec7c`. Independent verification matched all 11 public assets, the full 412-file source archive and the 138-file Cargo package. The default channel now selects 0.3.11 for Linux and Windows; the existing macOS selection and GitHub latest designation are unchanged.
