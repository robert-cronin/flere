# Flere 0.3.17

- Single-click a Files inspector entry to open its directory, image preview or
  editor. j/k and arrows still select without opening; Enter opens the selection,
  and right-click keeps the context menu. Opening a file focuses its editor on
  both wide and narrow screens without turning the click into a text selection.
- Clean, unlisted `nofile` buffers used by editor UI plugins no longer cause a
  close confirmation when read-only or hidden and empty. Editable scratch
  buffers with text, listed scratch buffers, write-handler buffers, unsaved
  file buffers and running jobs remain guarded.
- Claude gateway guidance now explains family aliases, the saved `/model`
  preference and automatic permission-checker model compatibility. Gateway
  profiles remain private configuration; this release changes no native
  permission mode or existing chat model.

These changes apply to newly opened editor integrations. Existing chats and
editors retain their processes across an update; no session is restarted by
these fixes. Linux x86-64 GNU core/companion and Windows x86-64 MSVC companion
are the release targets; macOS acceptance remains separate.
