# Flere 0.3.12

Routine native agent hooks no longer rewrite the entire saved coordination history on the supervisor thread that handles keyboard and mouse input. This reduces intermittent typing delays as agent activity and saved history grow. Message submission, delivery and acknowledgment receipts retain their durable writes. A supervisor refresh saves the current hook observations before replacing the process, preserving permission and activity guards; a failed save leaves the current sessions running.

An isolated Linux workload with eight harmless native stand-ins and roughly 4.9 MB of synthetic history reduced input-request p95 from 80 ms to 2 ms and typing-to-terminal p95 from 82 ms to 12 ms. Supervisor writes fell from 842 MB to 0.15 MB over 12 seconds. These measurements cover the local supervisor and PTY path, not SSH transport or physical desktop rendering. Card layout changes and durable mailbox changes still require synchronous saves and can be delayed by storage contention.

Use **Ctrl+Space, Shift+K**, verify the offered version, then **Enter** to apply. Over SSH, the updater handles the remote core and local companion together. This release targets Linux x86_64 GNU and the Windows x86_64 companion; it adds no macOS prebuilt. Linux prebuilts require glibc 2.39 or newer.
