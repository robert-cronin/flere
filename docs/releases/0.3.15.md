# Flere 0.3.15

Claude Code now receives card-scoped Flere MCP tools and native hooks. Verified SessionStart hooks save the exact conversation for resume, and prompt/tool/Stop boundaries surface compact unread-message notices. Existing native settings, hooks, permissions and MCP sources are preserved. Optional private harness profiles configure an Anthropic-compatible gateway such as Vekil. Claude has no native idle queue; messages arriving after it stops wait for the next supported boundary or Flere tool reply.

New Flere shells integrate interactive `claude` and `claude --resume` alongside Codex. Management and print commands pass through. The integration does not approve native permission or repository-trust prompts. One bounded Claude Code 2.1.300 no-tools prompt succeeded through Vekil; real interactive behavior remains a separate acceptance check.

Mouse-wheel scrolling and Shift+PageUp/PageDown reach native full-screen chats through the SSH companion, with coordinates relative to the terminal pane. Inline output and Flere navigation retain local scrollback. Tests exercise the actual bridge, supervisor and PTY route while preserving an unsent draft. Refresh retains live processes; if an older supervisor already lost the native mouse-mode state, the application must re-emit that mode before wheel routing can work.

Long-lived Codex chats retain verified executable identity across native client upgrades, including Linux executables whose old path was removed. Delivery uses the live process executable and rejects changed or ambiguous targets.

Formatting, strict offline Clippy, both Rust suites, release builds and disposable managed-install checks passed in the Linux/Windows release workflow. Automated integration tests use owned native stand-ins; physical Windows/SSH scrolling and real interactive Claude acceptance remain separate checks.

Publication passed all required jobs in [run 38664896767](https://github.com/robert-cronin/flere/actions/runs/38664896767), using source `eded4e9`. All 11 public release assets independently matched the sealed candidate. The stable channel selects 0.3.15 for Linux x86_64 GNU and the Windows x86_64 MSVC companion.
