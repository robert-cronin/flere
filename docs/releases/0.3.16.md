# Flere 0.3.16

The SSH companion now enables mouse reporting and bracketed paste before replying
to the remote handshake. Previously, a coordinated update could hide the remote
UI's startup output behind its local progress screen, discarding that input-mode
setup. After dismissing the update, mouse gestures and image paste could stop
working until reconnecting. The companion now retains those modes throughout the
update without forwarding hidden screen content or replaying input.

An existing companion with the earlier bug may still need one detach and reconnect
after updating. Running chats and drafts remain intact. This fix does not
reconstruct native mouse settings discarded by older supervisors; if new chats
scroll but a preserved older chat does not, explicitly exit and resume that same
conversation so the native application re-emits its settings.

The regression covers fragmented hidden startup, hidden shutdown, the refresh
handshake and a repaint that contains no input-mode setup. The private gateway
profile remains local; native model-family aliases must name the intended models
advertised by that gateway.
