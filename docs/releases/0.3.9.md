# Flere 0.3.9

[Flere 0.3.9](https://github.com/robert-cronin/flere/releases/tag/v0.3.9) publishes the Linux x86_64 core and companion, Debian package, Windows x86_64 companion ZIP and complete source. The immutable release and core Cargo crate come from `9fbd2db`; [release run 35223044320](https://github.com/robert-cronin/flere/actions/runs/35223044320) passed all nine required jobs.

## Agent and session changes

- Ordinary `codex` and `codex resume` commands inside Flere shells register with their card, retaining Flere tools and native paste support.
- Reopening a card with no open tabs restores its last recorded native conversation. Starting an agent uses a keyboard-accessible harness selector.
- Native message queue submission is recorded separately from inbox reads and acknowledgment.
- Peer agents can inspect a terminal and send ordered text, paste, named keys or arbitrary bytes. Exact target identities and transient single-use tickets guard against stale targets and accidental replay.
- Sidebar attention badges remain distinct from card selection.

Terminal input remains subject to the actual task authority and native approval rules. It does not establish delegated human consent.

## Validation and availability

The native Linux producer passed offline core and companion formatting, strict Clippy, tests and release builds, distribution fixtures, managed install/reinstall and ELF checks. The Windows producer passed native MSVC checks, packaging and all six portable alias checks. All 11 public downloads were independently compared with the sealed release, including the complete 408-file source archive. Cargo publication and its archive verification also passed.

Linux prebuilts require glibc 2.39 or newer. Physical clipboard, desktop and live external SSH acceptance remain separate from hosted checks. No new macOS prebuilt is included; its arm64 download remains the unsigned 0.3.0 release. Homebrew and Scoop remain at their separately published 0.3.8 pins.

## Update over SSH

Open Update Flere with **Ctrl+Space, Shift+K**. Use **Tab** to switch between remote core and local companion. A blank field uses saved source policy; a registered remote development checkout can take precedence over a pinned package URL. To choose this release explicitly, enter:

- Remote core: `https://github.com/robert-cronin/flere/releases/download/v0.3.9/flere-x86_64-unknown-linux-gnu.manifest.json`
- Windows companion: `https://github.com/robert-cronin/flere/releases/download/v0.3.9/flere-connect-x86_64-pc-windows-msvc.manifest.json`

Press **Enter** to prepare and verify the pair, check that both candidates show 0.3.9, then press **Enter** to apply or **Esc** to cancel. The coordinated flow preserves terminal sessions and drafts, reconnects the companion and reports which components activated. Explicit URLs stay pinned for future updates; default-channel installations follow the promoted target map during explicit preparation.

The new terminal tools require the updated supervisor. Existing native chats can use the scoped `agent-call` interface after activation; new MCP tool names use the harness's supported catalog reload.
