# Flere 0.3.19

- The SSH companion's update screen now uses a centered panel with concise
  version information and clear preparation, installation and return stages.
  Press **D** for build details; existing keyboard controls remain available.
- Successful updates return automatically to Flere after the updated frontend
  is verified, with a completion notice. Failed or partial updates keep their
  recovery guidance open. Sessions, layouts and drafts are preserved.
- Queued updater input is discarded at completion, including bracketed pastes
  that cross the return boundary, so it cannot spill into the resumed terminal.

Linux x86-64 GNU core/companion and Windows x86-64 MSVC companion are the release
targets; macOS acceptance remains separate.
