# Flere 0.3.7

When `flere ssh HOST` needs to install a remote core, it now selects the release
for that remote platform from the verified release index. Linux and Mac downloads
can advance independently. A compatible existing remote installation still
attaches without downloading a package.

Default selection verifies the exact manifest size, SHA-256, version, component
and target before using the existing payload, protocol and installation checks.
An invalid or unavailable index stops with an error; it does not silently select
an older release. Explicit manifest URLs and local packages remain available.

The shell bootstrap also uses the per-platform index through an installer pinned
to an immutable Git commit and checksum. Existing saved copies of the shell
loader keep their original pin. The Release workflow prepares an index promotion
after public download verification; signed publication uses the existing local
signer until a trusted automated signing path is configured.

The Linux/Windows release profile contains Linux x86_64 core and companion
binaries (glibc 2.39+), a Debian package, the Windows x86_64 companion ZIP and
source. Both Windows aliases run the companion; there is no native Windows core.
macOS arm64 prebuilt selection retains explicitly unsigned v0.3.0, and Intel Mac
prebuilt selection remains unavailable. Physical clipboard and package catalogue
acceptance retain their separate limits in the [distribution guide](../distribution.md).
