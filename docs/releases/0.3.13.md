# Flere 0.3.13

The SSH companion no longer repaints every project icon whenever terminal text or the mascot changes. Repeated Sixel writes shared the event loop that forwards keyboard and mouse input. A negotiated damage flag now preserves intact icon pixels while restoring them after screen clears, layout or font changes, and late image arrivals. Either older peer retains the existing repaint behavior; no saved-state migration is involved.

A deterministic companion test with 16 icons and 120 unchanged frames reduced repeated icon output from 6.1 MB to zero. A real isolated bridge test verifies text updates, resize, menus and font changes through the production companion icon painter. These checks establish the reduction in rendering work; they do not measure physical Windows input latency or SSH round-trip time.

Companion diagnostics now record local input-queue and remote-render steps taking at least 50 ms, at most once per five seconds for each step. These entries contain durations only, with no typed text or terminal contents.

Use **Ctrl+Space, Shift+K**, verify the offered version, then **Enter** to apply. Both the core and companion need this version to use the optimization. This release targets Linux x86_64 GNU and the Windows x86_64 MSVC companion. Linux prebuilts require glibc 2.39 or newer.
