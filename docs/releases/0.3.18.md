# Flere 0.3.18

- Agents can archive stopped cards with `archive_workspace` and unhide them with
  `restore_workspace`, through MCP or the scoped `agent-call` CLI. Every agent
  has the same access. Archiving hides a card without changing its workflow
  status or accepting its work.
- Both commands preserve files, worktrees, metadata, saved conversations, tab
  order and selection. Archiving refuses live or unreaped terminals; restoring
  starts no program. Exact supervisor epoch and complete card metadata checks
  reject stale requests, and failed saves roll back the visibility change.
- Existing chats can use the scoped CLI once the updated supervisor is active.
  The new MCP tool names may require the native harness's supported catalog
  reload. Updates preserve existing chat and shell processes.

Linux x86-64 GNU core/companion and Windows x86-64 MSVC companion are the release
targets; macOS acceptance remains separate.
