# Flere 0.3.14

Agent context now supports compact, progressive and incremental reads. Routine calls keep essential coordination visible while exact messages, decisions, checkpoints and handled history remain available through IDs and bounded pages. The deterministic coordination evaluation reduced response bytes by about 86% for its incremental workflow. Six synthetic model cases passed correctness checks; they do not establish uniform token, latency or compaction improvements.

Long-lived coordination history no longer shares the legacy 8 MiB JSON-file limit with acknowledgements and card updates. When a save crosses that bound, Flere activates indexed SQLite storage, retaining original bodies, provenance, retry identities and exact saved sessions. Cold startup and ordinary reads retrieve bounded records. Lifecycle updates commit atomically; uncertain outcomes require verified recovery before storage operations continue. No history is automatically deleted.

The activated store uses saved-state version 11. Older binaries without that reader cannot open it. Small stores retain their existing JSON format. The live-refresh format remains 10, and refresh preserves existing session identities without launching stopped chats. Editor-cache retention reads the indexed layout and retains snapshots if storage cannot be verified.

The supervisor services terminal input and output while durable jobs complete, avoids unnecessary layout/snapshot work, and reduces repeated output serialization. These changes do not establish a fix for physical Windows/SSH typing latency.

Local validation passed 629 Rust tests, strict offline Clippy, release build and formatting, plus 16 offline model-evaluator controls. A synthetic Linux growth test retained 7,200 records containing 116 MB of originals with about 7.3 MiB cold RSS. Native integration uses harmless stand-ins through real supervisor, ownership, socket and hook paths; physical power loss and cross-platform runtime acceptance remain separate limits. See [evaluation methods](../evaluations.md) and [storage design](../design/coordination-storage.md).

This release targets Linux x86_64 GNU and the Windows x86_64 MSVC companion. Linux prebuilts require glibc 2.39 or newer. Publication passed all required jobs in [run 35435727869](https://github.com/robert-cronin/flere/actions/runs/35435727869), and the stable channel selects 0.3.14. Use **Ctrl+Space, Shift+K**, check the offered version, then **Enter** to apply. Existing macOS channel selection and GitHub's latest designation are retained.

A disposable Linux 0.3.13 → 0.3.14 coordinated-update check passed with the published core and companion payloads, preserving session identities and an unsent draft. SSH and HTTP were local stand-ins; this does not establish physical Windows acceptance. All 11 public release assets matched the sealed artifact, and the published Cargo crate matched the 158 expected source files.
