## Incorporated fix

A Windows checkout with `core.autocrlf=true` embeds CRLF in POSIX shell scripts.
Remote `sh` then treats the carriage return as part of tokens and rejects
`set -eu`. The bootstrap now normalizes line endings in its own embedded scripts
before quoting them. Caller arguments retain their existing strict validation.
The regression covers probe, receive and cleanup scripts, quoted paths and the
rejection of control characters in arguments.

## Remaining failures and unperformed checks

Holding a horizontal or ladder key produces initial movement, a pause, then
repeated movement. The tested terminal did not negotiate enhanced keyboard event
reports. The legacy 180 ms hold timeout versus the reported approximately 500 ms
initial repeat delay is a plausible explanation, not measured event timing.
Increasing the timeout alone would also lengthen movement after a tap. Track a
console-owned input solution and preserve paste, Unicode, mouse, local forms and
console restoration; do not change system settings or monitor global keys.

Native-chat image/text paste, draft retention/no submission, the complete graphical
cleanup matrix, effective font/zoom/scaling, additional file/port/update scenarios
and the remaining game/screensaver matrix are still incomplete. The report did
not include a redistributable Windows executable or public-download acceptance.
Keep Windows package-manager publication pending the appropriate exact-payload
checks; see [the current procedure](../windows-acceptance-handoff.md).

Original reports and screenshots are retained privately. Public documentation
summarizes observations without publishing host details, chat identities or local
operational paths.
