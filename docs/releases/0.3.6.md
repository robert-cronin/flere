# Flere 0.3.6

Agent messages stay bound to the verified conversation across stop and resume.
Retries reuse the request ID, and final delivery rechecks the conversation's
identity. A different or ambiguous conversation cannot receive that message.

Scoop bucket installations and the official WinGet community source now receive
package-manager upgrade guidance. Flere verifies the installed package, profile,
manifest and executable before recognizing ownership. Use the same package
manager for upgrades; in-app Apply remains disabled for managed installations.

Saved-state and refresh-handoff formats advance to schema 8. This version reads
supported older data (saved state 2–8 and refresh 1–8). Schema-7 binaries cannot
read newly written schema-8 data, so reverting an executable alone is not a safe
downgrade.

The Linux/Windows release includes Linux x86_64 core and companion binaries
(glibc 2.39+), a Debian package, the Windows x86_64 companion ZIP, and source.
Both Windows command names run the companion: use `flere ssh ALIAS` to connect
to a Linux or macOS workbench. There is no Windows core in this release.

macOS signed binaries, physical desktop/clipboard checks and package catalogue
acceptance remain separate. See the [distribution guide](../distribution.md)
for current channel availability. The shared GitHub latest/default installer
pointer remains v0.3.0 until target-specific discovery is implemented.
