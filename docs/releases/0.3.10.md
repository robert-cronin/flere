# Flere 0.3.10

The updater discovers compatible published releases without requiring manifest URLs. Official managed installations check the small release index after opening a window and every four hours; a notice shows when a new version is available. Set `FLERE_NO_UPDATE_CHECK=1` to disable these passive checks.

**Ctrl+Space, Shift+K** finds, downloads and verifies the latest release. Review the versions and press **Enter** to apply, or **Esc** to cancel. Over SSH, this updates the remote core and local companion together, reconnects and preserves terminal sessions and drafts. The success or failure stays visible until dismissed. **R** retries a failed check, and **A** opens custom package sources. Automatic updates never run a registered development script.

Package-manager installations retain their owning update method. The automatic route verifies the channel's manifest sizes and SHA-256 pins, payloads, platform, version and protocol compatibility before presenting a frozen installation plan. It never installs in the background or downgrades either component.

## Upgrading from the earlier source form

A companion that still shows two source fields needs this explicit selection once:

- Remote core: `https://github.com/robert-cronin/flere/releases/download/v0.3.10/flere-x86_64-unknown-linux-gnu.manifest.json`
- Windows companion: `https://github.com/robert-cronin/flere/releases/download/v0.3.10/flere-connect-x86_64-pc-windows-msvc.manifest.json`

Press **Enter** to verify, review both versions, then **Enter** to apply. Subsequent normal Update actions discover releases automatically, including when the retained Windows launcher uses a pinned source receipt.

The published target profile covers Linux x86_64 GNU and the Windows x86_64 companion. Linux prebuilts require glibc 2.39 or newer. No new macOS prebuilt or package-manager channel is included.
